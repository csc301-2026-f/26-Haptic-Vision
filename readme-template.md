Haptic Visions is developing dynamic tactile display technology that allows blind and low-vision users to physically feel digital content. Their system converts images of websites and other interfaces into real-time 3D representations, using a surface made of movable tactile pixels. Their goal is to create a tool that provides spatial information that could be difficult to understand through audio alone. 

## Description about the project
A continuous screen capture would feed visual content into HapticVision’s AI tool, which would translate the content into a tactile/vector representation displayed as a 3D model on their physical device. The user would have the applicable software installed on their computer, which would capture and process the content on their screen and represent it in 3D. This could help address some of the common challenges blind and low-vision users encounter in the online world by giving them a physical understanding of a webpage’s layout and helping them navigate it more efficiently.
